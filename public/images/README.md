# Drop your photos here

Filenames matter — the site auto-detects them by exact name (any of
`.jpg`, `.jpeg`, `.png`, `.webp`). No code or config changes needed.

| File | Used for | Recommended size |
|---|---|---|
| `hero-1` … `hero-4` | Rotating hero background (4 slides) | 1920×1200+, landscape |
| `route-map` | Route section map graphic | 1000×1250, portrait (4:5) |
| `day-sigiriya` | Itinerary — Sigiriya | 1200×900, landscape (4:3) |
| `day-kandy` | Itinerary — Kandy | 1200×900, landscape (4:3) |
| `day-nuwaraeliya` | Itinerary — Nuwara Eliya | 1200×900, landscape (4:3) |
| `day-ella` | Itinerary — Ella | 1200×900, landscape (4:3) |
| `day-mirissa` | Itinerary — Mirissa | 1200×900, landscape (4:3) |
| `avatar-1` … `avatar-3` | Testimonial guest photos | 300×300, square (gets cropped to a circle) |
| `og-image` | Social share preview (Open Graph / Twitter card) | 1200×630, landscape |

Example: add `hero-1.jpg` here and the first hero slide picks it up
on the next `npm run dev` / `npm run build` automatically. Until a file
exists, that slot shows a labeled placeholder instead.
